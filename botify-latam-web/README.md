# BOTIFY LATAM — Sitio web

Sitio estático creado desde cero para BOTIFY LATAM.

## Archivos
- `index.html`: estructura y contenido.
- `style.css`: diseño responsive, animaciones y componentes.
- `script.js`: menú móvil, animaciones al hacer scroll y FAQ.
- `sitemap.xml`: mapa del sitio para buscadores.
- `robots.txt`: reglas para rastreadores.
- `favicon.ico`: icono temporal del sitio.
- `img/`: logos proporcionados.

## Antes de publicar
1. Reemplaza `https://tudominio.com` en `sitemap.xml` y `robots.txt` por tu dominio real.
2. Revisa precios, alcance de planes y cualquier costo de terceros.
3. Mantén los nombres de archivos dentro de `img/` o actualiza sus rutas en `index.html`.
4. Sube todos los archivos conservando la misma estructura.

## Publicación
Puedes subir la carpeta a GitHub Pages, Netlify, Cloudflare Pages o cualquier hosting estático.

## Nota comercial
La página presenta los servicios bajo la marca BOTIFY LATAM. No menciona herramientas internas utilizadas para prestar el servicio.
